## Player avatars

`avatars.h` — eight 16x16 overworld sprites, generated by `tools/gen_avatars.py`
from [pret/pokered](https://github.com/pret/pokered) (`gfx/sprites/*.png`), the
Pokémon Red/Blue disassembly. Only the first frame of each sheet is used, recoloured
onto a four-entry palette.

**These are Nintendo / Game Freak / Creatures artwork and are _not_ licensed for
redistribution**, unlike the PMD sprites (CC BY-NC) or the badges (CC BY 3.0).
The disassembly publishes them for research and preservation; that is not a
licence grant, and this project has no rights over them.

They are here because the project owner asked for the real sprites, and this
entry exists so that the choice is documented rather than quietly made. If the
repo is published, the clean approach is the same one already recommended for
the PMD sprites above: **ship `tools/gen_avatars.py` and not `avatars.h`**, so
each user fetches the art themselves — the script needs only `curl` and takes a
second to run.

## Battle backgrounds

`tools/backs/*.png` — twelve 240x112 scenes, one day and one night per biome,
packed into `backs.h` by `tools/gen_backs.py`.

**Provenance not established.** These were supplied for the project rather than
sourced by it. Before this repo goes public, confirm where they came from and
under what licence, the same way the PMD sprites are accounted for above — and
replace them if that cannot be answered.

## Gym badge artwork

**https://github.com/SteGriff/pokemon-badges** — SVG recreations of the first 40
league badges, Kanto through Unova, traced from Bulbapedia. Stephen Griffiths,
2011, **CC BY 3.0** (attribution required, commercial use permitted).

`svg/Kanto.svg` holds the eight badges, and `tools/gen_badges.py` renders it
with `rsvg-convert`, isolates each and packs them into `badges.h` at 32x32.

**CC BY requires this attribution to travel with anything built from it** --
firmware binaries included, not just the source.
